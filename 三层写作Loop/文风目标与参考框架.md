# 文风目标与参考框架

## 总目标

建立一种清晰、可读、可修改的写作风格。

这种文风要同时服务两类读者：

1. 人类读者：能快速理解文章在讲什么、为什么这样讲、证据在哪里。
2. AI 修改者：能识别段落功能、论证关系、材料层级和可修改位置。

因此，目标不是形成一种“漂亮文风”，而是形成一种结构透明、语义稳定、证据边界清楚的写法。

---

# 一、三类参考来源

## 1. GRE / GMAT / LSAT 的阅读理解与写作能力

这些考试可以提供一套“清晰文本”的底层能力模型。

重点不是学习考试作文模板，而是学习它们如何要求读者和写作者处理复杂文本。

可提取的能力包括：

- 抓住主旨；
- 区分主论点和支持论据；
- 识别作者态度；
- 分辨事实、判断、推论；
- 识别段落之间的逻辑关系；
- 发现论证假设；
- 判断证据是否真正支持结论；
- 对复杂观点做限定，而不是过度断言；
- 用理由和例子支持一个清楚立场。

转化为写作规则：

- 每一节必须有一句可独立陈述的核心判断。
- 每一段必须能标出自己的功能：提出判断、解释概念、展开例子、补充证据、处理反例、过渡总结。
- 观点、证据、推论、限定要分开写，不能混在一句话里。
- 段落之间要能说清关系：因果、转折、补充、比较、递进、让步、总结。
- 所有复杂判断都要能接受反向追问：证据是什么？假设是什么？适用边界在哪里？

---

## 2. 商业杂志和严肃新闻写作

参考对象包括科技、政治、经济、商业类长文和分析文章。

重点不是模仿某一家媒体的腔调，而是提炼风格变量较稳定的新闻写作范式。

可提取的能力包括：

- 开头迅速进入问题；
- 用具体场景承载抽象判断；
- 在早期交代读者为什么要关心；
- 把背景信息拆成必要的小块；
- 用事实、数字、人物、机构、事件支撑叙述；
- 让段落推进像“问题展开”，而不是像“资料堆放”；
- 对争议问题保持归因和限定；
- 避免空泛形容词，用动作、变化和冲突推动文章。

转化为写作规则：

- 开头优先回答：发生了什么？这为什么重要？读者需要先知道什么？
- 抽象概念必须落到一个场景、案例、人物、组织、制度或决策问题上。
- 背景信息只在读者需要它时出现，不提前铺太长。
- 每个事实材料都要承担任务：证明、解释、对比、制造问题、显示后果。
- 对有争议的判断要写清来源和语气：谁认为？基于什么？还有什么限制？
- 句子优先使用清楚动词，少用堆叠式形容词。

---

## 3. 学术简报与政策简报的表达规范

学术简报和政策简报适合提供“高密度但不晦涩”的表达规范。

可提取的能力包括：

- 先说明问题；
- 给出关键发现；
- 解释证据来源；
- 区分发现、解释和建议；
- 让结构便于扫读；
- 用小标题承载逻辑；
- 对结论加上证据等级和适用边界；
- 避免把研究过程写成流水账。

转化为写作规则：

- 每一节开头要能给出本节的“简报式摘要”。
- 小标题应该表达判断或问题，不只是主题名。
- 关键发现要靠前，方法和背景靠后。
- 证据要说明类型：数据、案例、研究、访谈、历史材料、理论推导。
- 结论要说明强弱：确定、较可能、可能、需要进一步验证。
- 如果文本面向初学者，专业细节应服务理解，而不是展示研究储备。

# 二、目标文风的核心变量

## 1. 结构透明

读者能看出文章的推进路径。

检查问题：

- 这一节在回答什么问题？
- 这一段承担什么功能？
- 前后段是什么关系？
- 这一处材料为什么出现？

## 2. 结论靠前

重要判断不要藏在段尾或长铺垫后。

推荐节奏：

1. 先给判断；
2. 再解释判断；
3. 再给例子或证据；
4. 最后补充限定或推进到下一点。

## 3. 具体例子优先

抽象论述要从具体情境进入。

优先使用：

- 一个真实或拟真的场景；
- 一个决策者面对的问题；
- 一个读者熟悉的现象；
- 一个能承载概念差异的案例。

避免：

- 一上来定义术语；
- 连续堆概念；
- 用宏大判断代替具体解释。

## 4. 证据边界清楚

每个判断都要能看出证据强度。

写作时区分：

- 事实：已经发生或可查证的事情；
- 解释：对事实的理解；
- 推论：从事实推出的判断；
- 建议：基于判断提出的行动方向；
- 限定：这一判断在哪些条件下成立。

## 5. 语言低噪音

语言要降低装饰性和模板感。

优先：

- 短句；
- 明确主语；
- 强动词；
- 具体名词；
- 清楚连接词；
- 必要限定。

减少：

- 空泛形容词；
- 连续抽象名词；
- 密集排比句；
- AI 式过渡句；
- 没有信息量的总结句。

## 6. 便于 AI 修改

文本应该让 AI 能准确识别可修改对象。

因此每段最好具备：

- 明确段落功能；
- 单一核心判断；
- 清楚证据位置；
- 可替换的例子；
- 可调整的语气强度；
- 明确的上下文连接。

# 三、可操作的段落模板

## 判断段

结构：

1. 本段最重要的判断。
2. 为什么这个判断成立。
3. 一个必要例子或证据。
4. 判断的边界或下一步。

适用：

- 概念解释；
- 理论判断；
- 章节主论点；
- 对材料的解释。

## 新闻解释段

结构：

1. 一个具体事实或场景。
2. 这个事实暴露了什么问题。
3. 背后的机制或背景。
4. 它对读者理解主线有什么作用。

适用：

- 科技、商业、政治、经济案例；
- 现实问题引入；
- 争议背景说明。

## 简报段

结构：

1. 关键发现。
2. 证据来源。
3. 对读者的含义。
4. 必要限定。

适用：

- 研究摘要；
- 政策说明；
- 数据或文献结论；
- 专业判断。

## 反驳与限定段

结构：

1. 先承认一个可能的反对意见。
2. 说明它在哪些方面成立。
3. 再指出它不能解释什么。
4. 回到本文主判断。

适用：

- 处理争议；
- 降低过度断言；
- 增强论证可信度。

# 四、自升级模块 / 编辑修改模式

现有“三层写作 Loop”已经有基础结构：方向、描写、编辑。

下一步不应只增加新的写作规则，而应增加一个“自升级模块”。这个模块的目标是让文章在多轮阅读、复述、诊断和改写中逐渐变清楚。

它不是一次性润色工具，而是一种编辑修改模式：

- 先让不同读者 agent 阅读原文；
- 再让它们复述自己理解到的内容；
- 对比“读者理解版本”和“作者原文意图”之间的差异；
- 找出叙述不清、逻辑跳跃、例子不足、术语未解释、语气过强、句子不顺的地方；
- 再进行局部改写；
- 改写后重新进入下一轮读者复述。

这个过程要重复进行，直到不同读者 agent 对文章的理解版本与原文意图基本一致。

---

## 1. 读者 agent 设定

每次检查文章时，至少假设三类读者：

1. **普通读者 agent**：没有系统专业背景，只能依靠文本本身理解文章。
2. **半专业读者 agent**：了解一些术语和领域常识，但不熟悉完整理论或技术细节。
3. **专业读者 agent**：能检查概念、逻辑、证据和专业表达是否准确。

必要时可以增加：

- 写作编辑 agent：只检查段落节奏、句子顺序和表达清晰度。
- 怀疑型读者 agent：专门寻找跳步、过度断言和证据不足。
- 初学者 agent：检查例子是否足够具体，术语是否解释到位。

---

## 2. 80% 理解阈值

一段文字的最低要求是：不同层次的读者 agent 应该能比较清晰地读出原文至少 80% 的意思。

这里的“80%”不是机械打分，而是检查三类一致性：

- **逻辑一致**：读者能复述出主要论点、推理顺序和段落关系。
- **细节一致**：读者没有遗漏关键事实、例子、限定和概念差异。
- **语气一致**：读者没有把谨慎判断误读成强断言，也没有把主要观点读成旁枝材料。

如果读者只能理解大概主题，但说不清论证路径，说明文章还不够清楚。

---

## 3. 复述检查

每一轮编辑时，先让读者 agent 做复述，而不是直接修改。

复述应包括：

1. 这段或这一节的核心意思；
2. 作者想证明什么；
3. 使用了哪些例子或证据；
4. 段落之间是什么关系；
5. 哪些地方读起来不确定；
6. 哪些句子需要重新斟酌。

复述不是摘要。摘要会压缩信息，可能掩盖问题。复述的任务是暴露理解偏差。

---

## 4. 偏差诊断

如果读者 agent 的复述和作者原意不一致，要先诊断偏差来源。

常见偏差包括：

- 核心判断太晚出现；
- 一段承担了太多功能；
- 术语从日常语境跳到专业语境，但没有提示；
- 例子没有明确服务哪个观点；
- 背景信息太多，主线被淹没；
- 句子过长，主语和动作不清楚；
- 连接词不足，读者只能自己猜逻辑；
- 语气太满，结论超过证据；
- 重要限定藏在句尾或括号里；
- 段落顺序不符合读者理解路径。

诊断时先说问题类型，再说修改方向。不要一发现不顺就直接重写。

---

## 5. 局部改写

改写要优先处理最影响理解的部分。

修改顺序：

1. 先改结构：段落顺序、段落功能、论证路径。
2. 再改判断：核心句是否提前，结论是否清楚。
3. 再改例子：例子是否具体，是否服务观点。
4. 再改句子：长句、搭配、指代、连接。
5. 最后改风格：节奏、重复、语气、词汇。

不要一开始只改词句。很多字句问题其实来自结构问题。

---

## 6. 再复述与停止条件

改写后，必须重新让读者 agent 复述。

如果复述仍然偏离原意，继续诊断和改写。

可以停止的条件是：

- 普通读者 agent 能说出文章在讲什么，并能抓住主要例子；
- 半专业读者 agent 能说出论证路径和关键概念；
- 专业读者 agent 没有发现明显概念错误、证据跳跃或语气过强；
- 编辑 agent 能确认段落功能清楚，句子没有明显卡顿；
- 读者复述版本与作者原意在逻辑、细节和语气上基本一致。

升级后的 skill 不应变成“写得像某某媒体”，而应变成：

> 用考试阅读的逻辑精度、新闻写作的可读推进、学术简报的证据规范，通过多轮读者复述和编辑诊断，写出人能读懂、AI 能继续修改的文章。

# 五、检查清单

写完一节后，至少检查以下问题：

- 本节核心判断能否一句话说清？
- 读者能否看出每段的功能？
- 每个例子是否服务一个明确观点？
- 是否区分了事实、解释、推论和建议？
- 是否有未经解释的术语？
- 是否有过度抽象的形容词堆叠？
- 是否有证据不足但语气过强的判断？
- 是否存在可以提前的结论句？
- 是否有段落只是展示知识、没有推进文章？
- 如果让 AI 修改，AI 能否知道该改结构、例子、语气还是证据？
- 普通读者 agent 能否复述出至少 80% 的核心意思？
- 半专业读者 agent 是否能说清论证路径和关键概念？
- 专业读者 agent 是否会发现概念、证据或语气上的问题？
- 读者复述版本和作者原意是否在逻辑、细节和语气上基本一致？

# 六、参考来源线索

这些来源不作为固定模板，而作为提炼写作规则的材料。

## 考试阅读与写作

- ETS GRE Analytical Writing：强调清楚表达立场、处理复杂性、用理由和例子支持观点。
- ETS GRE scoring guide：可用于提炼组织、发展、支持、语言清晰度等评分维度。
- GMAC GMAT Verbal Reasoning：可用于提炼主旨、支持观点、推论、逻辑结构、风格和论证评估。
- LSAC LSAT Reading Comprehension：可用于提炼主旨/支持观点、事实/态度区分、段落关系、作者结论路径。

## 新闻写作

- Reuters journalistic standards：可用于提炼准确性、归因、平衡、避免无归因意见等规则。
- Guardian style guide：可用于提炼清楚、普通、当代、精确的语言原则。
- AP news values and principles：可用于提炼匿名来源、归因和事实核查的基本新闻规范。

## 学术简报与政策简报

- IDRC policy brief guide：可用于提炼目的前置、单一主题、精简材料、普通语言等原则。
- Harvard Kennedy School policy memo guide：可用于提炼 bottom line upfront、问题与建议的结构比例。
- UNC Writing Center policy briefs：可用于提炼研究摘要、政策选项和行动建议之间的区别。
- World Bank policy brief materials：可用于提炼面向非专业读者、研究发现简化、建议前置等规则。
